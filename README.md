# Storhamar U12 – lag og kamper

Vite + Tailwind-app med lagoppsett og serieoppsett for Storhamar U12 (født 2015), sesongen 2026–2027.
Kan installeres som app på telefonen (PWA).

- `npm run dev` – utviklingsserver
- `npm run build` – validerer serieoppsettet og bygger til `dist/`
- Data ligger i `src/data.js`

Publiseres automatisk til https://sdalen.github.io/sil15/ ved push til `main`
(Settings → Pages → Source: **GitHub Actions**).
